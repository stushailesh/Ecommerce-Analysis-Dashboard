# Ecommerce-Analysis-Dashboard
## Project Overview
### This project presents an interactive E-commerce Sales & Customer Behavior Dashboard developed using Microsoft Power BI and Published to Power BI Service.
The objective of this project is to analyze e-commerce customer activity, purchasing behavior, revenue, product/category performance, traffic patterns, pricing trends, and promotional effectiveness.
🛠️ Tools Used

#### *Power BI |Power BI Service | DAX | Power Query | Excel*

The dashboard converts raw transactional and customer-event data into actionable business insights that can help an e-commerce company understand:
<br>
How customers interact with products
<br>
Which categories generate the highest sales value
<br>
When customer traffic is highest
<br>
Which channels perform better
<br>
How purchasing behavior varies by day and hour
<br>
Which products/categories have high customer interest
<br>
How promotions influence customer activity and revenue opportunity
<br>
